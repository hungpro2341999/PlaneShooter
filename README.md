# PlaneShooter
Web 3D arcade flight game — Three.js + TypeScript + Vite.

Chơi thử: `npm install && npm run dev`. Build: `npm run build`.
Đọc trước khi code: [AI_CONTEXT.md](AI_CONTEXT.md) • [docs/architecture.md](docs/architecture.md) • [docs/conventions.md](docs/conventions.md)

Điều khiển: chuột lái • W/S ga • A/D liệng • Shift tăng tốc • hỗ trợ tay cầm (Gamepad API).
