# Art Decisions — asset/realistic

1. **Đổi style toàn diện**: bỏ low-poly hoạt hình theo chốt của chủ repo. Style guide low-poly cũ chỉ còn trên nhánh asset/concept + asset/fixes; file style-guide.md trên nhánh này là bản bán tả thực và là bản hiện hành duy nhất.
2. **Đọc code main trước khi làm**: main hiện là bản bash.tv — model trong game đang dựng bằng code (`src/models.js`: makeJet theo palette, mũi −Z; makeBomber; makeMissileMesh), hiệu ứng hạt ở `src/effects.js` (màu lửa #ff6a1a, khói đen #3a3633 — khớp style mới), trời/fog ở `src/world.js` (fog hiện là Fog thường #cfe7f3, chưa phải FogExp2 xám vàng). Bộ thử đợt này là **asset rời** để duyệt hướng; việc gắn vào code (thay makeJet bằng GLB, đổi fog, nạp skybox) là việc của chat CODE ở phase sau.
3. **Model thử tự dựng bằng code** (trimesh: thân bằng mặt xoay theo biên dạng + cánh extrude) thay vì tải Sketchfab: các trang model thường đòi tài khoản/tải qua giao diện, và đợt trước Kenney 403 + Poly Pizza đòi token. Tự dựng giữ được đúng ngân sách tris và giấy phép CC0 sạch; hình dáng tiêm kích hiện đại 2 vây đứng theo ảnh lineup. Đánh đổi: độ chi tiết bề mặt (panel line, rivet) thua model sculpt thật — chấp nhận cho bản duyệt hướng, asset-plan đã ghi đường thay bằng model ngoài cho P0/P1.
4. **Màu ngụy trang trên model thử nằm ở vertex color (COLOR_0)** theo từng mặt (mảng ngụy trang + vệt bẩn), chưa có bộ texture PBR 2048 (Albedo/ORM/Normal) và chưa nén Draco/KTX2 — đó là bước production trong asset-plan mục 11/14, không giả vờ đã có.
5. **Skybox/VFX thử vẽ bằng code** theo đúng palette ảnh mẫu (trời xám vàng, khói đen #2A2725, lõi nổ cam #FF6A1A) để code game đối chiếu trực tiếp với `src/effects.js`.
6. **Ký hiệu hư cấu**: model thử không gắn cờ/quân hiệu thật; ký hiệu duy nhất là chevron trừu tượng trên vây đứng (theo ảnh mẫu) — thực hiện ở bước texture, bản GLB thử chưa gắn decal.
